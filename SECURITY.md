# Security policy

## Reporting

Please do not open a public issue for a suspected vulnerability or exposed credential. Contact the repository owner privately through the profile contact channel.

## Public-copy policy

This repository must contain synthetic data only. Production credentials, customer information, logs, database exports, and private media are out of scope and must never be committed.

If a secret is accidentally exposed, revoke and rotate it immediately, remove it from the complete Git history, and review access logs. Deleting only the latest file is not sufficient.
